jinge 框架示例

jinge 是一个小巧的前端界面框架：基于 Proxy 实现数据绑定，使用 tsx 描述模板，不使用虚拟 DOM。 下面是按主题排列的示例，每个示例都在独立目录里，既可以在线预览，也可以对照源码阅读。

    最小示例：打包后 3.2 kB（gzip 1.5 kB），同样功能的 Vue 版 61 kB、React 版 220 kB。
  • 条件渲染 If 源码
    If 组件，以及 ? :、&& 的编译糖
  • 表单输入 源码
    原生表单控件与 vm 数据绑定
  • 简易待办 源码
    列表增删改查与 localStorage
  • Todo MVC 源码
    路由、过滤器与模块级 store
  • 数据侦听 源码
    watch / vmWatch、深度监听与 changedPath
  • 过渡动画 源码
    Transition 与 TransitionGroup
  • 递归组件 源码
    用函数组件渲染树形结构
  • Ref 与生命周期 源码
    ref、expose、onMount / onUnmount
  • 集成 ECharts 源码
    在组件中挂载第三方图表库
  • 插槽 Slots 源码
    默认插槽、命名插槽、作用域插槽与插槽透传
  • 上下文 Context 源码
    跨层级传递主题与配置，避免 props 逐层透传
  • 事件 Events 源码
    原生事件、自定义事件与受控组件
  • 列表渲染 源码
    keyed 重排、嵌套列表、空态与 nextTick
  • 表单 Form 源码
    input/select/radio/checkbox 等控件的绑定与汇总
  • 样式 Styling 源码
    class 组合、style 字符串与 CSS 变量主题
  • 动态组件 源码
    Dynamic 切换、lazy 异步加载与状态重建
